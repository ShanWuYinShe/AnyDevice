# AnyDevice - 局域网全平台音频无线扬声器 🎵

> 将台式机/电脑的声音实时无线传输到手机、平板、另一台电脑或电视上播放。解决台式机没有物理音箱的困扰，纯系统原生支持，零驱动安装，支持**任意多端同时接收（1 对多广播）**。

---

## 🌟 核心特性

- **纯系统原生支持，零驱动安装**：直接使用现代操作系统的原生音频环回（Windows WASAPI Loopback / macOS CoreAudio / Linux PipeWire），无需安装任何第三方驱动。
- **全平台零安装接收端**：利用现代浏览器 HTML5 Web Audio API，**手机/平板/电脑无需安装任何 App**，相机或扫码枪扫码即播。
- **任意多端同时播放**：支持 1 对多广播，多个设备可在同一个局域网内同时作为音箱出声。
- **超低延迟架构**：48kHz 16-bit 双声道立体声，网络丢包抗抖动缓冲，端到端延迟低至 30~50ms，音画同步极佳。
- **屏幕防休眠 (WakeLock)**：手机打开网页后自动保持屏幕常亮，防止手机锁屏休眠中断音频。
- **实时音频可视化**：网页端内置示波器动态波形，直观确认声音传输状态。

## 🚀 极简使用说明

### 1. 启动服务端

在电脑上直接运行程序：

- **Windows 台式机**：双击运行 `any_device.exe`
- **macOS / Linux**：终端执行 `./any_device`

程序启动后会自动：
1. 直接连接系统当前默认音频输出（如显示器 HDMI/DP 音频、主板音频、USB 声卡等）；
2. 打印控制台 ASCII 二维码；
3. 输出局域网访问网址（如 `http://192.168.1.100:8080`）。

### 2. 手机/任意端扫码播放

1. 确保手机与电脑连接在**同一个局域网 Wi-Fi** 下；
2. 用手机相机扫码或在浏览器输入控制台打印的局域网 IP；
3. 点击网页上的 **「开启扬声器播放」**，手机立即作为音箱发声！
4. **多设备同时加入**：局域网内任意手机、平板、电脑均可同时打开链接，全部同步出声。

## 🛠️ 常用命令行参数

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `-port` | `8080` | 指定 HTTP 和 WebSocket 服务端口 |
| `-mode` | `auto` | 音频捕获模式：`auto` (自动)、`loopback` (系统回环)、`capture` (输入端/麦克风)、`test-tone` (生成 440Hz 测试音频) |
| `-list` | `false` | 列出本机所有可用音频设备并退出 |
| `-device` | `-1` | 手动指定特定设备序号（通过 `-list` 查看） |
| `-no-qr` | `false` | 关闭终端二维码打印 |

#### 实用示例：

- **查看所有声卡设备**：
  ```bash
  any_device -list
  ```
- **纯测试串流（无需任何真实声卡）**：
  ```bash
  any_device -mode test-tone
  ```

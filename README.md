# AnyDevice - 跨端音频与鼠标多设备无线映射中心 🎵🖱️

> 将台式机/电脑的声音与鼠标实时无线映射到手机、平板、另一台电脑或电视上。支持在 Web UI 上**自主勾选开启哪种设备通道**（音频 / 鼠标），纯原生跨平台支持，零驱动安装。

---

## 🌟 核心特性

- **多设备通道自主选择**：在接收端 Web 界面上，用户可以自由勾选：
  - 🎧 **系统音频 (System Audio)**：将电脑系统声音实时串流到该端作为无线扬声器。
  - 🖱️ **本地鼠标 (Local Mouse)**：将电脑屏幕光标与按键状态实时映射到该端画布，支持光标跟随、点击波纹动效与按键高亮。
  - **同时开启或按需独立开启**：不同设备可选择不同通道（例如手机听声音，平板看鼠标轨迹）。
- **纯系统原生驱动**：
  - 音频：Windows WASAPI Loopback / macOS CoreAudio / Linux PipeWire。
  - 鼠标：Windows `user32.dll` / macOS `CoreGraphics`，60FPS 低延迟无损抓取。
- **全平台零安装接收端**：利用现代浏览器 HTML5 Web Audio 与 Canvas API，**手机/平板/电脑无需安装任何 App**，相机或扫码枪扫码即用。
- **1 对多广播**：局域网内任意数量设备可同时连接。
- **超低延迟架构**：丢包抗抖动缓冲，毫秒级响应。
- **屏幕防休眠 (WakeLock)**：手机打开网页后自动保持屏幕常亮，防止手机锁屏休眠中断。

## 🚀 极简使用说明

### 1. 启动服务端

在电脑上直接运行程序：

- **Windows 台式机**：双击运行 `any_device.exe`
- **macOS / Linux**：终端执行 `./any_device`

程序启动后会自动：
1. 挂载系统音频通道与本地鼠标捕获引擎；
2. 打印控制台 ASCII 二维码；
3. 输出局域网访问网址（如 `http://192.168.1.100:8080`）。

### 2. 手机/任意端扫码选择映射设备

1. 确保手机与电脑连接在**同一个局域网 Wi-Fi** 下；
2. 手机扫码打开控制台网页；
3. 点击 **「开启设备映射」**；
4. 在页面顶部的**通道选择卡片**上自由点击切换：
   - 点击 **🎧 系统音频**：展开/折叠音频示波器、音量与延迟控制；
   - 点击 **🖱️ 本地鼠标**：展开/折叠虚拟屏幕画布，实时呈现台式机光标滑动、按键点击波纹。

## 🛠️ 常用命令行参数

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `-port` | `8080` | 指定 HTTP 和 WebSocket 服务端口 |
| `-mode` | `auto` | 音频捕获模式：`auto` (自动)、`loopback` (系统回环)、`capture` (输入端/麦克风)、`test-tone` (生成 440Hz 测试音频) |
| `-list` | `false` | 列出本机所有可用音频设备并退出 |
| `-device` | `-1` | 手动指定特定设备序号（通过 `-list` 查看） |
| `-no-qr` | `false` | 关闭终端二维码打印 |

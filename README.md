# AnyDevice - 跨端双向设备映射中心 🎵🖱️🎮

> 将台式机/电脑的声音与鼠标实时无线映射到手机、平板、另一台电脑或电视上。**自带原生独立桌面应用窗口（双击直接弹窗，无需浏览器），既能当被映射端（电脑投音画到手机），也能当映射端（手机触控板反向遥控电脑鼠标）**。智能路由过滤虚拟机网卡，支持在 UI 上自由切换角色与设备通道。

---

## 🌟 核心特性

- **自带原生独立桌面应用窗口（无需浏览器）**：
  - 在 Windows 上双击 `any_device.exe`，直接弹出**专属独立桌面应用窗口**（无浏览器地址栏、无标签页杂质），就像一个正规的原生桌面软件一样使用。
  - 窗口内直接附带清晰的高清连接二维码、局域网连接地址、音视频示波器、鼠标状态与触控板。
  - 关闭窗口即安全退出程序，也可以通过 `-no-ui` 运行于纯后台守护进程模式。
- **真正对等的双向角色（既能当映射端，也能当被映射端）**：
  - 📥 **接收模式（本端当音箱/副屏）**：
    - 🎧 **系统音频**：把电脑声音无损串流到手机/平板播放；
    - 🖱️ **光标同步**：把电脑光标实时投射到接收端画布监视。
  - 🎮 **控制模式（本端当遥控器/无线触控板）**：
    - 手机屏幕秒变**无线触控板**！单指滑动真实移动电脑鼠标，单指轻点左键，双指轻点右键，双指上下滑动模拟鼠标滚轮，支持实体左右键。
- **智能网卡与 IP 路由解析**：
  - 采用操作系统路由探测（OS Routing Table Resolution）自动定位真实物理出网网卡，**自动剔除 VMware / VirtualBox / WSL / Hyper-V / Docker 等虚拟网卡干扰**。
  - 支持 `-ip` 命令行参数随时手动指定监听发布的局域网 IP。
- **秒级设备发现与稳定在线状态**：
  - 节点启动时立即突发广播（约 0.2 秒内全网可感知，不再等满一个心跳周期），并向每个物理网段发送定向广播，多网卡/虚拟机环境也能可靠互发现；
  - 手机/浏览器接入按来源归并（刷新页面不产生重复条目），断开后 ≤5 秒即在列表显示离线；
  - 手机或另一台电脑打开控制台时，设备列表**不会显示它自己**（按查看者过滤）。
- **设备改名跨重启持久化**：
  - 本机名称与对端备注保存在本地配置文件（默认用户配置目录下 `AnyDevice/config.json`，可用环境变量 `ANY_DEVICE_CONFIG` 指定其他路径），重启不再丢失；
  - 对端备注优先于对端广播名显示，且**不会**被后续发现心跳覆盖。
- **按需订阅，空闲零空转**：
  - 本机 UI 窗口默认不订阅音频/鼠标/键盘流，只有真正开启映射时才通过 `set_mapping` 动态订阅；无人订阅时音频捕获引擎静默，显著降低空闲 CPU 与网络开销。
- **纯系统原生驱动**：
  - 音频：Windows WASAPI Loopback / macOS CoreAudio / Linux PipeWire。
  - 鼠标：Windows `user32.dll` (`GetCursorPos` + `mouse_event`)，纯原生无驱动。
- **全平台零安装接收端**：手机/平板端扫码即用，无需安装额外 App。

## 🚀 极简使用说明

### 1. 启动程序（电脑端）

直接双击运行：
- **Windows 台式机**：双击运行 `any_device.exe`
- **macOS / Linux**：双击或终端执行 `./any_device`

程序启动后会自动弹出**独立桌面应用窗口**，窗口中央直接显示连接二维码与本机局域网地址。

### 2. 手机/另一端连接

拿起手机对着电脑屏幕上的二维码一扫，即可连接：
- 切换到 **「📥 接收端模式」**：点击勾选 **🎧 系统音频** 或 **🖱️ 本地鼠标**，手机作为音箱或监视器出声出画面。
- 切换到 **「🎮 控制端模式」**：手机变身无线触控板，手指在灰色触控板区域滑动，电脑上的真实光标随之移动！

## 🛠️ 常用命令行参数

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `-no-ui` | `false` | 纯后台/命令行模式运行，不弹桌面应用窗口 |
| `-port` | `8080` | 指定服务端口 |
| `-ip` | `""` | 手动指定对外广播的局域网 IP（多网卡/复杂网络环境时使用） |
| `-mode` | `auto` | 音频捕获模式：`auto` (自动)、`loopback` (系统回环)、`capture` (输入端/麦克风)、`test-tone` (测试音) |
| `-list` | `false` | 列出本机所有可用音频设备并退出 |
| `-device` | `-1` | 手动指定特定设备序号（通过 `-list` 查看） |
| `-no-qr` | `false` | 关闭终端二维码打印 |

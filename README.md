# AnyDevice - 跨端双向设备映射中心 🎵🖱️🎮

> 将台式机/电脑的声音与鼠标实时无线映射到手机、平板、另一台电脑或电视上。**既能当被映射端（电脑投音画到手机），也能当映射端（手机触控板反向遥控电脑鼠标）**。智能路由过滤虚拟机网卡，支持在 Web UI 上自由切换角色与设备通道。

---

## 🌟 核心特性

- **真正对等的双向角色（既能当映射端，也能当被映射端）**：
  - 📥 **接收模式（本端当音箱/副屏）**：
    - 🎧 **系统音频**：把电脑声音无损串流到手机/平板播放；
    - 🖱️ **光标同步**：把电脑光标实时投射到接收端画布监视。
  - 🎮 **控制模式（本端当遥控器/无线触控板）**：
    - 手机屏幕秒变**无线触控板**！单指滑动真实移动电脑鼠标，单指轻点左键，双指轻点右键，双指上下滑动模拟鼠标滚轮，支持实体左右键。
- **智能网卡与 IP 路由解析**：
  - 采用操作系统路由探测（OS Routing Table Resolution）自动定位真实物理出网网卡，**自动剔除 VMware / VirtualBox / WSL / Hyper-V / Docker 等虚拟网卡干扰**。
  - 支持 `-ip` 命令行参数随时手动指定监听发布的局域网 IP。
- **纯系统原生驱动**：
  - 音频：Windows WASAPI Loopback / macOS CoreAudio / Linux PipeWire。
  - 鼠标：Windows `user32.dll` (`GetCursorPos` + `mouse_event`)，纯原生无驱动。
- **全平台零安装接收端**：利用现代浏览器 HTML5 Web Audio 与 Canvas，手机无需安装任何 App，扫码即用。
- **1 对多广播**：多设备可同时连入，自由选择监听音频或遥控鼠标。

## 🚀 极简使用说明

### 1. 启动服务（电脑端）

在电脑上直接运行程序：

- **Windows 台式机**：双击运行 `any_device.exe`
- **macOS / Linux**：终端执行 `./any_device`

程序启动后会自动过滤虚拟网卡并输出真实物理局域网地址（如 `http://192.168.1.100:8080`）与二维码。

### 2. 手机/任意端打开并切换模式

手机扫码打开网页后，可在顶部自由切换：
- 切换到 **「📥 接收端模式」**：点击勾选 **🎧 系统音频** 或 **🖱️ 本地鼠标**，手机作为音箱或监视器出声出画面。
- 切换到 **「🎮 控制端模式」**：手机变身无线触控板，手指在灰色触控板区域滑动，电脑上的光标随之移动！

## 🛠️ 常用命令行参数

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `-port` | `8080` | 指定 HTTP 和 WebSocket 服务端口 |
| `-ip` | `""` | 手动指定对外广播的局域网 IP（多网卡/复杂网络环境时使用） |
| `-mode` | `auto` | 音频捕获模式：`auto` (自动)、`loopback` (系统回环)、`capture` (输入端/麦克风)、`test-tone` (生成 440Hz 测试音频) |
| `-list` | `false` | 列出本机所有可用音频设备并退出 |
| `-device` | `-1` | 手动指定特定设备序号（通过 `-list` 查看） |
| `-no-qr` | `false` | 关闭终端二维码打印 |

#### 多网卡指定 IP 示例：
```bash
# 如果机器上有多个虚拟机网卡，可手动锁定真实物理 Wi-Fi 的 IP
any_device -ip 192.168.1.105
```
